# Project Operating Rules & Agent Guidelines

## ⚠️ STRICT GIT & REPOSITORY POLICY (ZERO AUTONOMOUS COMMITS/PUSHES)
- **NEVER execute `git commit` autonomously.**
- **NEVER execute `git push` autonomously.**
- **NO staging, committing, or pushing code to any local or remote Git repository without explicit, prompt-level user confirmation and approval.**
- Always ask the user directly before running any Git command that alters Git history or syncs with remotes (`git commit`, `git push`, `git merge`, `git rebase`).
- You may run read-only Git commands (`git status`, `git diff`, `git log`) to verify working tree status, but destructive or persisting actions require prior user permission.
